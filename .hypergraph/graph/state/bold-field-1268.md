## Current

Dogfooding is this project's evidence that the protocol holds when it is used rather than described, and it has two genuinely separate bases, which are this node's children: **Self-host** — this repo running under its own protocol — and **Field** — repos that adopted it, three of which this project did not write [rec: late-sage-5549].

- **The two are not the same test and were never meant to be.** Self-host proves the loop closes where the author can fix the tool mid-cycle; field use is where defects that survive the author's assumptions are found, and it has produced six of them so far [rec: northern-willow-0469] [rec: fresh-spire-9002].
- Forward-looking intent was moved out of this node onto frontier nodes when the forward-work convention landed, which is why it holds structure rather than plans [rec: patient-limit-9007].

## Negative knowledge

None here — the self-host and field lessons live on the two children.
